# ThinkWar 
ThinkWar es un juego RPG por turnos creado en Java y se juega en terminal. Es un proyecto creado como Practica Final de la asignatura de Programación. 

## 🚀 Cómo ejecutar el proyecto
1. Clona el repositorio con:
   https://github.com/hades-12-Cerberus/ThinkWar.git
   cd ThinkWar

2. Compila los archivos Java:
   javac *.java

3. Ejecuta:
   java ThinkWar


Cabe destacar que es un proyecto de aprendizaje por lo que seguramente se pueda perfeccionar más o existan algunos errores. 
Gracias por probarlo!!
